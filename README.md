# Davilex IMG Extractor

This repository contains a python script that can extract rcs.img from London Racer along with other img + ind file combinations from other Davilex games.

## Usages

Make sure you have python 3 installed, then you can run the script from your command line interface like this:

```
python3 extract_files.py rcs
```

You can replace rcs with the full path and name of the img file you want to extract. Do not add the extension when running this script. The extracted files will be put in the `result` directory in the working directory from where the script was run.
